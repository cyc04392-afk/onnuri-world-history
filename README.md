# 온누리 세계사

세계사능력검정시험(한국역사교육진흥회) 대비 학습 앱(PWA). 빈칸 채우기(간격 반복) · 용어 사전(키워드 말풍선) · 기출 동형 객관식 · 서술형 대비 · 출제 경향 분석.

- iPhone: Safari로 열기 → 공유 → **홈 화면에 추가**
- Android: Chrome로 열기 → 메뉴 → **홈 화면에 추가** (또는 설치)
- 마이페이지 → **전체 내용 오프라인 저장**을 한 번 누르면 인터넷 없이도 사용 가능

## 단계
1단계: 앱 본체 + 01~08강(문명의 발생, 중국 고대~송·원) ✅
2단계: 09~16강(명·청, 일본, 서아시아·인도, 그리스)
3단계: 17~25강(로마~국민 국가)
4단계: 26~34강(제국주의~현대·시사)

## 자료
- 빈칸·용어·연표·서술형: 중등 세계사·동아시아사 교육과정 범위로 이 앱을 위해 작성
- 동형 기출: 공식 기출(12·13·14회)의 주제·형식을 분석해 새로 쓴 문항(공식 문제지는 외부 게시 금지라 원문 미수록)
- 사진·지도: 위키미디어 공용(각 자료에 저작자·라이선스 표기)
